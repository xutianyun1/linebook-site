# Linebook 官方网站

Linebook App 的公开页面（隐私政策 + 支持页），通过 GitHub Pages 托管。

## 页面

- `privacy.html` — 隐私政策（App Store 上架必填）
- `support.html` — 支持页（App Store 的「支持 URL」）

## 访问地址

部署到 GitHub Pages 后：

- 隐私政策：`https://<你的用户名>.github.io/linebook-site/privacy.html`
- 支持页：`https://<你的用户名>.github.io/linebook-site/support.html`

## 更新联系方式

如邮箱变更，搜索并替换 `xutianyunch@outlook.com` 即可。
